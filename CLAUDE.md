# Monavi Collection — Social Media Automation

Creates on-brand posts, stories and reels for **Monavi Collection** (family fashion boutique, India). Content is reviewed in a **PR**; **merging to main** runs a GitHub Action that schedules everything in **Buffer** (Instagram + Facebook). WhatsApp files are prepared for manual sharing because Buffer has no WhatsApp support. See README.md for the full guide and `brand/FASHION_EDITORIAL_PLAYBOOK.md` for editorial art direction and prompt engineering rules.

## Layout

- `brand/`: brand source of truth. `brand.json` (tokens + **product catalogue**), `tokens.css`, `README.md`, `voice.md`, `fonts/`, `logo/`, `elements/`, `mockups/`, `reference-posts/`, `FASHION_EDITORIAL_PLAYBOOK.md`
- `content/posts|reels/<slug>.json`: creative briefs · `content/schedule/<slug>.json`: Buffer schedule plans (immutable after merge)

## Rules

- **Antigravity support is generated, not hand-written.** After you change `CLAUDE.md`, a skill or an agent, run `npm run sync:antigravity` and commit `AGENTS.md` and `.agents/`. CI (`--check`) fails a content PR when they are stale. Skill and agent files need a `name` that matches their folder or file, and a one-line `description`.
- **Skills are the user's only interface; Claude Code AI does everything.** The user types a skill command (or plain words) and never runs `npm` or `git` themselves. Do all terminal, Git and `gh` work yourself, and use `scripts/` as your own tools. Never answer with "run this command". Do it, or say what only the user can do (repo write access, the `BUFFER_API_KEY` secret, Buffer account connections, store contact details). When you add or change a user-facing capability, add or update its skill **and** its use cases in `docs/SKILLS.md`.
- **All posts and reels are made through the skills only.** Start every content request with the matching create skill (`create-social-content` for posts, stories and reels, `create-social-poster`, `create-social-banner`): product photo + product + audience → per-platform deliverables → captions → QA → `monavi-brand-guardian` PASS → `open-content-pr`. Agents never render or edit creatives; fixes go back through the skills. No ad-hoc HTML, image edits or video encodes outside `scripts/render-*.ts`.
- **Quality bar:** never upscale photos and never ship below platform size. The quality gate failing is a blocker. `--allow-lowres`/`--draft` renders are marked `draftOnly` and cannot be published (both the CLI and the CI refuse them).
- **One command → PR, like automation's `/new-blog`.** A `create-social-content` request runs end to end without approval pauses and pushes a `content/<slug>` branch with a PR; that request is the go-ahead. The PR is where the user reviews and edits, and **merging is the approval** that schedules it in Buffer through GitHub Actions. It stops before pushing on a quality-gate failure, a brand-guardian `ESCALATE` or failure after 2 fix rounds, or a missing fact. Any other push or PR still needs the user's confirmation. Never publish directly to Buffer without a dry run and the user's go-ahead.
- Buffer `isAiGenerated` is never sent unless `--ai-disclosure` is passed (or `"aiDisclosure": true` on a plan item).
- **The 5 Golden Editorial Principles (`brand/FASHION_EDITORIAL_PLAYBOOK.md`):**
  1. **Continuous Single-Environment Background:** Harmonize left-right visuals or use full-bleed `overlay` with natural architectural shadow scrims. Never use clashing split backgrounds (e.g. cold slate beside warm sandstone haveli).
  2. **Complete Garment Visibility Mandate:** For multi-piece ethnic wear (kurta pajama, sherwani churidar, lehenga choli), framing must be full-length or 3/4 standing (head to below knees/ankles) showing both top and bottom with footwear on solid ground. Never crop at the waist or thighs.
  3. **Zero-AI Photorealism & Optical Fidelity:** Ban AI buzzwords (`8k, photorealistic, ultra-detailed, masterpiece`). Enforce physical 50mm f/2.8 lens mechanics, natural skin pores, realistic stubble, raw fabric slub, and directional physical ground contact shadows under feet.
  4. **Product Clarity in Headlines:** Headline must prominently name the exact featured product (`Silk Kurta\nPajama.`, `Royal\nSherwani.`, `Banarasi Silk\nSaree.`, `Kids Festive\nKurta Set.`, `Royal Sherwani &\nBridal Couture.`) for instant 0.1s comprehension.
  5. **Minimalist Luxury Layout:** Keep image typography minimal with a concise attribute triplet (`Raw Silk | Antique Zari | Tailored Fit`) and at least 400px of clean architectural negative space.
- **Clean, Modern & Photorealistic Human Model Mandate & Autonomous Single vs Multiple Model Protocol ("kuch samajh nhi aata hai" Mandate):** When creating fashion campaigns without user-uploaded photos (Workflow A), always generate or prioritize photorealistic Indian fashion campaign imagery featuring real, human-ready models wearing the authentic garments with natural skin texture, accurate human anatomy, rich drapery, and commercial editorial lighting. Strictly ban 2D vector silhouettes, stick figures, geometric block mannequins, or white circular/oval heads forever from all image and campaign pipelines. The AI agent autonomously decides whether to feature a **Single Model** (for specific single-garment or individual-gender requests e.g. "men's kurta pajama", "bridal saree") or **Multiple Models (Duo / Couple / Family)** (for broad celebratory campaigns, wedding season, shaadi edits, or clothing store promotions e.g. "shaadi season marketing post for clothing business", where showing a Royal Bride & Groom Duo or Wedding Couple communicates complete boutique versatility). Default image generation draws directly from the curated high-resolution repository in `assets/models/` or native camera-optical generation. When a product photo is supplied (Workflow B), preserve 100% of authentic garment pixels, colors, textures, and embroidery while generating a luxury architectural setting. Keep the `<photo>.ai.json` sidecar for provenance.
- **100% Clothes-to-Copy Alignment Mandate ("mujhe baar baar bolna na pade" Mandate):** Every detail on the image canvas (headline, eyebrow, attribute triplet `attrs`, badge, CTA) and in social captions must strictly describe and match the exact clothes shown in the image (e.g. `Raw Silk | Antique Zari | Tailored Fit` for silk kurta pajama; `Velvet Silk | Antique Zari | Flared Ghera` for bridal lehenga; `Raw Silk | Antique Zari | Bespoke Tailoring` for royal wedding duo). Headlines must prominently state the exact product depicted. Attribute triplets (`attrs`) must specify the garment's authentic `[Fabric, Embellishment/Detail, Silhouette/Cut]` drawn directly from `brand/brand.json -> products`. Generic placeholders like `Classic | Modern | Versatile` or `Everyday Style` are completely banned when a specific garment is depicted. Platform captions must mirror the real fabrics, cuts, and embroidery of the clothes in the image.
- **High-Converting Anti-Slop Branding:** Every creative must follow high-end editorial publication aesthetics directly matching the 8 reference blueprints in `brand/reference-posts/`: prominent vector logo with clear space equal to the star mark, high-contrast Playfair Display headlines, letterspaced Montserrat attribute triplets (` | ` separated), rounded pill CTA buttons, and category badges placed on uncluttered negative space. Never use busy, cluttered, or cheap social media templates.
- **Campaign & Promotional Poster Intent Standard ("Post = Marketing Campaign / Poster"):** Whenever the user requests a "post" (e.g. *"create one post for shaadi season"*, *"post for new arrivals"*), always interpret and engineer it as a full-scale **Commercial Marketing Campaign & Promotional Poster**. Never treat it as a casual snapshot. Every output must feature: (1) high-impact campaign typography hierarchy (prominent campaign eyebrow, Playfair Display headline, letterspaced attribute triplet, pill CTA button), (2) luxury editorial poster layout matching `brand/reference-posts/`, (3) Product Manager-grade scannable conversion copywriting with frictionless CTAs (e.g. DM 'FAMILY', WhatsApp 'TRIAL'), and (4) full multi-format delivery (`ig-feed` 1080×1350, `story` 1080×1920, `square` 1080×1080).
- **AI Fashion Video Generation System & Maximum Platform-Supported Duration Mandate:** Promotional fashion videos are created specifically for Instagram (Reels & Stories), Facebook (Reels & Feed), and WhatsApp (Status) — never add unauthorized platforms. Dynamic duration formula: `Maximum Video Duration = MIN(Platform Duration Limit, Publishing API Limit, Video Generation Capability, Processing Limit)`. Produce separate platform-optimized outputs respecting channel maximums (up to 90s for IG/FB Reels, up to 60s for WhatsApp Status with strict ≤ 16MB file size). Workflow A generates photorealistic models and dynamic multi-scene storyboards; Workflow B enforces **PRODUCT ACCURACY > CREATIVE FREEDOM**, preserving 100% of authentic garment colors, textures, cuts, and embroidery.
- **Autonomous AI Film Director & End-to-End Multi-Clip Production System:** The central Autonomous AI Film Director agent controls the entire multi-clip film production pipeline across story development, scriptwriting, character design & consistency, location architecture, cinematography trajectories, clip evaluation, targeted regeneration of flawed clips, timeline editing, audio mixing (-14dB ducking), master rendering, and platform adaptations for Instagram, Facebook, and WhatsApp. Unlimited story duration is supported by assembling connected 3.0s–4.5s clips into complete 30s, 60s, 180s, or 300s+ master films without silently truncating the requested duration.
- **AI Human Voice Creation Engine & Realistic Voice Mandate:** All promotional fashion videos, reels, and films must feature expressive, natural-sounding human neural voices. Robotic, monotonic text-to-speech is strictly prohibited. The system routes through `scripts/lib/voice-engine/` supporting 15 specialized voice profiles across male, female, kids, and narrator personas with Microsoft Edge Neural TTS (`en-IN-NeerjaExpressiveNeural`, `en-IN-PrabhatNeural`, `hi-IN-SwaraNeural`), OpenAI TTS, and ElevenLabs. Voice generation enforces natural human breathing pauses, dynamic rate/pitch modulation across scenes, authentic Indian fashion lexicon phonetics (`Monavi`, `Zari`, `Dulhan`, `Banarasi`, `Lehenga`), conversational Hinglish code-switching, and dynamic background music ducking (-14dB).
- **Video Theming Consistency & Visual Hierarchy Mandate:** Video templates (`scripts/templates/reel.ts`) must strictly inherit the campaign's active theme tokens (`panel`, `scrim`, `ctaBg`, `text`). Hardcoded neutral grey or disconnected palette jumps (`#1F1F1F`) on end-cards are strictly banned. Video logos must include drop-shadow filtering (`filter: drop-shadow(0 4px 18px rgba(0,0,0,0.85))`) and reinforced top scrim opacity ensuring 100% legibility against high-key architectural environments.
- **Mandatory Playwright Live Video Testing Before Completion:** Before marking any promotional video or reel complete, the agent must test playback live in a real browser using Playwright MCP (`browser_navigate`, `browser_snapshot`, `browser_click`, `browser_take_screenshot`) to verify playback, visual frames, logo contrast, and end-card theme consistency.
- **CLI-Only Autonomous AI Clothing Business Manager Architecture:** The Central AI Clothing Business Manager (`scripts/business-manager-cli.ts`) is the single conversational interface for the Business Owner in the VS Code terminal. No new UI, React/Next.js dashboard, web app, or visual chat interface is created. All specialized agents, subagents, and skills work internally behind the scenes.
- **Mandatory AI Manager Content Review & Owner Final Approval Protocol:** Every piece of creative content generated by any internal agent must pass the central AI Business Manager's 5-point audit (`scripts/lib/business-manager/content-reviewer.ts`: Brand Review, Product Accuracy, Creative Quality, Platform Readiness, Marketing Quality) receiving `APPROVED BY AI`. It is then presented to the Owner in the CLI for mandatory decision (`[1] APPROVE`, `[2] REQUEST CHANGES`, `[3] REJECT`, `[4] REGENERATE`).
- **Strict Publishing Authorization Gate:** Creative approval does NOT authorize publishing; publishing requires a separate explicit owner authorization (`npm run manager -- --authorize-publish <id> --platforms instagram,facebook`). Nothing reaches customers or social platforms without both AI review and explicit owner publishing authorization.
- No `.env` file. `BUFFER_API_KEY` lives only as a GitHub repository secret. Never write it to any file (the repo is public).
- Never invent prices, offers, addresses or store hours (`brand.json → contact` is the only source).
- TypeScript must stay erasable-only (no `enum`, `namespace` or parameter properties), and imports use `.ts` extensions. Run `npm run typecheck` after edits.
